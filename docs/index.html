1. Introduction

The Second Brain Wearable Companion is an open-source hardware pendant and cognitive logging system. Built around the ESP32-C6 RISC-V SoC, the device records high-fidelity voice dictations, classifies your neural intent, and pushes structured tasks, reminders, and voice memories into a Next.js database dashboard.

Ultra-low Latency Streams

Dictate notes directly from your chest. The system formats I2S microphone inputs into signed 16-bit PCM WAV headers and streams them to the server over WiFi in less than 3 seconds.

NVS Cache Configuration

SSID, agent hosts, display brightness, and LED modes are cached locally on the ESP32 Non-Volatile Storage (NVS) flash partition. Configuration updates dynamically sync during heartbeat checks.

2. Hardware Schematic

The Second Brain system is composed of an ESP32-C6 controller connected to an I2S digital microphone, an I2C OLED screen, and tactical status components. Use the pin configuration below to wire your board.

Peripheral ESP32-C6 Pin Signal Description
INMP441 Microphone GPIO 4 SCK (Serial Clock) I2S clock line
INMP441 Microphone GPIO 5 WS (Word Select) L/R channel frame clock
INMP441 Microphone GPIO 20 SD (Serial Data) Audio data output pin
INMP441 Microphone GND / VCC GND / 3.3V Power pins. L/R select tied to GND.
SSD1306 OLED (I2C) GPIO 6 SDA (I2C Data) OLED display serial data
SSD1306 OLED (I2C) GPIO 7 SCL (I2C Clock) OLED display serial clock
WS2812B NeoPixel GPIO 8 DI (Data Input) Addressable RGB status pixel
Action Button GPIO 1 TACTILE (PULLUP) Trigger record when pulled to Ground

3. Firmware Installation

The device firmware is located in the firmware/ directory. Follow the compilation steps below using the Arduino IDE or the command-line upload script.

Library Dependencies

Ensure you have installed the following libraries inside the Arduino Library Manager:

  • ArduinoJson (v6.x or v7.x) for heartbeat JSON schema operations
  • Adafruit SSD1306 and Adafruit GFX for OLED rendering
  • Adafruit NeoPixel for controlling the onboard WS2812B LED status behaviors

Step-by-Step Compilation

// 1. Open firmware/config.h and set your WiFi and Next.js host credentials:
#define DEFAULT_WIFI_SSID "Sri Krishna Pg 41"
#define DEFAULT_WIFI_PASS "srikrishnafour"

// Point this to your server machine's local IP address
#define DEFAULT_AGENT_HOST "192.168.29.8" 
#define DEFAULT_AGENT_PORT 3000
// 2. Connect the ESP32-C6 to your computer and execute upload.sh:
$ cd firmware
$ chmod +x upload.sh
$ ./upload.sh

The shell script will automatically search for the correct ESP32 serial port (ttyUSBx / ttyACMx) and build and flash the firmware using the arduino-cli.

4. API Endpoint Reference

The wearable coordinates with the Next.js server using a series of JSON HTTP endpoints. The device must pass its ID and Bearer authentication token for validation.

POST /api/device/register

Registers the hardware node in the database during system boot. 

// Request Payload:
{
  "deviceId": "second-brain-001",
  "name": "Second Brain C6 Wearable",
  "token": "dev-token-xyz123"
}
POST /api/device/heartbeat

Triggered by the device every 10 seconds. Transmits current battery level and reads pending settings or command payloads queued in the dashboard. 

// Response Schema from Server:
{
  "success": true,
  "settings": {
    "brightness": 100,
    "ledBehavior": "rainbow",
    "recordingDuration": 5,
    "wifiSsid": "Sri Krishna Pg 41"
  },
  "command": "notification", // optional
  "title": "Calendar Reminder",
  "message": "Project review meeting in 10m"
}
POST /api/device/voice

Processes audio voice streams. Accepts binary Mono PCM wav data. The headers X-Device-ID and Authorization must be passed. 

// Response from Server:
{
  "success": true,
  "transcript": "Add task finish schematic documentation",
  "response": "✓ TASK CREATED\n\nFinish schematic documentation"
}

5. Web Dashboard Guide

The dashboard at /dashboard allows you to monitor and customize your Second Brain device:

  • Overview Console: Display the device connectivity state, dynamic battery percentage, and dispatch custom alerts and commands directly to the OLED display.
  • Tasks Queue: View tasks that have been transcribed and created from your voice. Mark them complete or delete them directly.
  • Memory Bank: Browse all note transcripts and filter items by hashtags.
  • Assistant Chat Link: Directly converse with your unified memory bank and ask questions powered by the server's AI (Gemini/OpenAI).

6. Troubleshooting

ESP32 Loop Reboots & WiFi Failures

If the device fails to connect to the custom WiFi credentials entered in the dashboard, it can enter a reboot loop. The firmware includes a safety stash mechanism: it stashes failed credentials, reboots, and automatically falls back to your hardcoded credentials in config.h to recover connectivity. Check your router configuration or SSID password if this loop occurs.

I2S Microphone Init Fails

If the serial logs print [I2S] Initialization FAILED!, double check the wiring pins for the INMP441 microphone. The SCK (clock), WS (word select), and SD (data) pins must match GPIO pins 4, 5, and 20 exactly. Also, make sure that the microphone's L/R selection pin is grounded so it streams on the left channel.
